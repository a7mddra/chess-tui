input:
1- algebraic notation:
    - e2 -> mark valid moves
        - e4 -> move piece
    - e2e4 -> move piece

2- slash for commands:
    - /help -> show commands
    - /new -> start new game
    - /undo -> undo last move
    - /resign -> resign game
    - /draw -> offer draw
    - /accept -> accept draw offer
    - /decline -> decline draw offer
    - /analyze -> analyze game
    - /flip -> flip board
    - /black -> play as black
    - /white -> play as white
    - /difficulty -> set difficulty level
    - /exit -> exit program
